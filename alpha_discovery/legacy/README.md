# Legacy Research Archive

This directory archives historical experiment code, one-off research scripts,
and tracked historical artifacts that are no longer imported by the active
pipeline.

Active development should happen in:

- `alpha_discovery/grammar_method/` for grammar search.
- `alpha_discovery/probe_method/` for field probing.
- `core/brain/` for Brain API submission and auth.
- `alpha_enhancement/agents/` for active LLM agents and deterministic test stubs.
- `alpha_enhancement/workshop/` for post-grammar repair/enhancement/admission.
- `alpha_enhancement/semantic_templates/` for promoted-alpha semantic templates and routing.
- `tools/` for maintained CLI wrappers and harnesses around active modules.

## Archived

```text
alpha_discovery/legacy.economic_search_method/        Historical theory-first economic search workspace,
                            including tracked candidate plans, theory logs,
                            debug payloads, and result artifacts.
alpha_discovery/legacy.llm_grammar_control_method/                  Historical LLM exploration loop and semantic novelty
                            tools, including tracked artifacts.
alpha_discovery/legacy.operator_skeleton_method/            Historical operator/relationship search experiments.
demo/                       Small demo scripts.
alpha_discovery/grammar_method/              Retired grammar helpers such as mechanical template
                            extraction and UCB experiments.
tools/                      Retired CLI scripts.
alpha_discovery/template_sweep_method/            Retired search helpers moved here only when they
                            stop being imported by active compatibility code.
*.py / *.sh at archive root  One-off sweep and manual analysis scripts.
```

Generated bytecode directories and `.pyc` files were not restored here. They
are rebuildable interpreter cache files, not source or research evidence.
The repository ignore rules intentionally allow files under `legacy/` so this
archive can include historical artifacts and logs if committed.

## Policy

- Do not add new production features here.
- Do not import legacy modules from active code.
- If an archived legacy idea becomes useful, extract only the small reusable
  part into `wq_alpha/`, `alpha_discovery/grammar_method/`, `alpha_discovery/probe_method/`, or a maintained
  `tools/` command.

The current compatibility packages `alpha_search/` and `alpha_multi/` remain at
the repository root because existing commands and tests still use those import
paths. They should stay thin facades over active `core` and `tools` modules.
